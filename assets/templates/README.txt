# 将截取的 UI 模板 PNG 放在此目录。

推荐：在 GUI「模板配置」中 Ctrl+V 粘贴截图并保存（无需手动改文件名）。

## 必需
- item_slot.png     — 目标装备本身（工艺槽或背包内，用于悬停复制）

## 单工艺模式必需
- craft_button.png  — 园艺台「执行工艺」按钮

## 预设模式可选
- reforge.png / augment.png / remove.png / randomise.png / sacrifice.png

## 安全停止可选
- not_enough_lifeforce.png — 生命力不足或无法支付提示

## 多步骤通货模式
蜕变石、改造石、增幅石、富豪石、重铸石、崇高石、剥离石图标已经内置。
流程页直接选择中文通货即可，不需要自行截图或维护这些识别图片。

截取时请使用与游戏相同的分辨率与 UI 缩放，尽量只截按钮文字/图标核心区域。
