# 将截取的 UI 模板 PNG 放在此目录。

推荐：在 GUI「模板配置」中 Ctrl+V 粘贴截图并保存（无需手动改文件名）。

## 必需
- item_slot.png     — 目标装备本身（工艺槽或背包内，用于悬停复制）

## 单工艺模式必需
- craft_button.png  — 园艺台「执行工艺」按钮

## 多步骤通货模式
不需要通货图片。通货靠「非绑定 / 通用」通货页的仓库格坐标定位，右键前再悬停按 Ctrl+C
核对中文通货名与堆叠数量，名称不符就不点击。流程页直接选择中文通货即可。
仓库里的 currency_*.png 只供单元测试与 scripts/calibrate-stash.cjs 标定仓库格使用，不打进安装包。

截取时请使用与游戏相同的分辨率与 UI 缩放，尽量只截按钮文字/图标核心区域。
